# Reference paper

This directory contains the preprint of the paper that `drl-cox` implements:

> Yeping Jin, Lauren Wise and Ioannis Ch. Paschalidis.
> **Distributionally Robust Learning in Survival Analysis.**
> Proceedings of the Conference on Health, Inference, and Learning (CHIL 2025),
> Proceedings of Machine Learning Research 287:1-12, 2025.

- Published version: <https://proceedings.mlr.press/v287/jin25a.html>
- Preprint: <https://arxiv.org/abs/2506.01348> (arXiv:2506.01348v2)
- Authors' code: <https://github.com/noc-lab/drl_cox>
